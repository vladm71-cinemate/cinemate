# Cinemate

Каталог фильмов и сериалов (TMDb) с просмотром раздач на TV Box.

**Два приложения:**
- **Cinemate** (телефон, Android 8.0+) — каталог, поиск, торренты, пульт для бокса
- **CinemateReceiver** (TV Box / Android TV, Android 8.0+) — приёмник: HTTP-сервер + экран списка раздач

## Возможности
- Каталог/поиск (RU/EN), фильтры: год, жанры, страны, сортировка
- Обход блокировок: DNS (DoH + UDP), прокси, режим «Мобильная сеть»
- «Смотреть»: поиск раздач по нодам, запуск на TV Box или на телефоне (TorrServe MatriX)
- Фильтры раздач: сезон × качество (телефон и ТВ-экран)
- Кнопки-«глаза»: запуск приложений на боксе (иконки приложений)
- Ожидаю/Отслеживать, уведомления о релизах и новых сериях
- Автообновление через GitHub Releases (раз в сутки)
- 9 языков интерфейса

## Установка
1. **Телефон:** поставьте `cinemate-<версия>.apk` (разрешите установку из неизвестных источников)
2. **Бокс:** поставьте `cinemate-receiver-<версия>.apk`, **откройте один раз вручную**
3. На экране ресивера разрешите **«Поверх других окон»** (жёлтая подсказка ведёт в настройки) — нужно для кнопок при закрытом ресивере
4. Телефон: Настройки → Просмотр на ТВ → включить → «Найти IP» → Тест → ✅
5. В роутере желательно закрепить IP бокса (DHCP-резервирование)

Данные: [TMDb](https://www.themoviedb.org/)
